Apps Script Web App Connection Setup

Follow these quick steps to hook up this web portal to your live Google Apps Script backend.

1

Deploy Web App in Google Apps Script

Open your linked Google Sheet $\rightarrow$ Extensions $\rightarrow$ Apps Script. Click Deploy $\rightarrow$ New deployment. Select type Web app. Set Execute as: Me and Who has access: Anyone. Click Deploy and copy the URL.

2

Set Script Properties

In Apps Script $\rightarrow$ ⚙ Project Settings $\rightarrow$ Script Properties, add:

  • GEMINI_KEY : Your Gemini API key from AI Studio
  • WEB_TOKEN : A secure passphrase (e.g. anantam_web_secure_token_2026)
3

Create config.js Locally

Copy web/config.example.js to web/config.js and paste your deployment URL and token:

window.CONFIG = {
  WEB_APP_URL: "https://script.google.com/macros/s/.../exec",
  WEB_TOKEN: "anantam_web_secure_token_2026",
  MOCK: false
};
